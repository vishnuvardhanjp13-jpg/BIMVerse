# BIMVERSE Website Versions

This public repository preserves each BIMVERSE website release in its own folder.

| Folder | Release | Contents |
| --- | --- | --- |
| `01_Version` | Version 1 | Original standalone landing page |
| `02_Version` | Version 2 | Preserved V2 storefront and product-delivery application |
| `03_Version` | Version 3 | Subscription BEP workspace and portal |
| `04_Version` | Version 4 | Connected BIMVERSE360 delivery workspace |

Each application folder is self-contained. Open its own `README.md` or `package.json` for project-specific setup information. Version 1 is a standalone HTML page and can be opened directly.
